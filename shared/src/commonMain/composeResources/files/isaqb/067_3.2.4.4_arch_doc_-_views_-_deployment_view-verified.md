## Question 1

What is the primary focus of the "Deployment View" in software architecture documentation?

- [ ] The internal logic and relationships of software components.
- [x] Which building blocks are deployed and executed on which hardware components, and how they
  interact via logical and physical channels.
- [ ] The dynamic behavior of the system during runtime.
- [ ] The external context and interfaces of the system.

<details>
<summary>Rationale</summary>
<p>

**Rationale:** Deployment View maps building blocks to hardware and shows logical/physical channel
interactions. Internal logic (Building Block View), dynamic behavior (Runtime View), and external
context (Context View) are separate views.

</p>
</details>
