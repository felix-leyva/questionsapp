## Question 1

What are the two main questions to consider when designing a graphical user interface, according to the text?

- [ ] What programming language will be used, and who will develop the interface?
- [x] How does the user interact with the system, and who controls navigation?
- [ ] How much data will be displayed, and what colors will be used for it?
- [ ] What is the budget for the user interface, and when will it be done?

<details>
<summary>Rationale</summary>
<p>

**Rationale:** GUI design focuses on user interaction style and navigation control. Programming language/developers are implementation details, data volume/colors are presentation concerns, and budget/timeline are project management, not design fundamentals.

</p>
</details>

## Question 2

Which of the following is a characteristic of an "Object-Oriented" interaction style, as exemplified by a desktop environment?

- [ ] A sequential flow where the software controls the navigation and prompts.
- [x] Users interact with virtual objects that behave like real things with drag-and-drop.
- [ ] Filling out forms with predefined fields and validation for each entry.
- [ ] Navigating through a tree-like menu structure with hierarchical options.

<details>
<summary>Rationale</summary>
<p>

**Rationale:** Object-oriented interfaces use virtual objects (files, folders) behaving like real things with direct manipulation (drag-and-drop). Sequential flow is question-answer style, forms are form-based interaction, and tree navigation is menu-driven style.

</p>
</details>

## Question 2a

What are the virtual objects typically found in an object-oriented desktop environment?

- [ ] Buttons, sliders, and checkboxes for input
- [x] Files, folders, and trash bins as objects
- [ ] Windows, dialogs, and menus for navigation
- [ ] Icons, cursors, and toolbars for interaction

<details>
<summary>Rationale</summary>
<p>

**Rationale:** Object-oriented desktops use files, folders, and trash bins as primary virtual objects representing real-world counterparts. Buttons/sliders are UI controls, windows/dialogs are containers, and icons/toolbars are interface elements, not the metaphorical objects themselves.

</p>
</details>

## Question 2b

What makes virtual objects in an object-oriented interface feel "real" to users?

- [ ] They have realistic visual textures and shadows for realism
- [x] They behave as if they were real physical things would
- [ ] They make sounds when manipulated by the user actions
- [ ] They have weight and physics simulations applied to them

<details>
<summary>Rationale</summary>
<p>

**Rationale:** Virtual objects feel real through behavioral similarity to physical things (dragging, dropping, containing). Visual realism, sounds, and physics are enhancements but not the core—behavior drives the metaphor.

</p>
</details>

## Question 2c

Which manipulation technique is characteristic of object-oriented interfaces?

- [ ] Double-clicking to activate objects and open them
- [x] Dragging and dropping objects between locations
- [ ] Right-clicking for context menus with options
- [ ] Keyboard shortcuts for object operations quickly

<details>
<summary>Rationale</summary>
<p>

**Rationale:** Drag-and-drop is the fundamental object-oriented manipulation technique, mimicking physical object movement. Double-clicking, right-clicking, and keyboard shortcuts are general interaction techniques, not specific to object-oriented interfaces.

</p>
</details>

## Question 3

What type of interaction style is characterized by a sequential flow where the software controls the control flow, such as in an ATM or a wizard?

- [ ] Object-oriented style
- [x] Question-answer style
- [ ] Form-based style
- [ ] Menu-driven style

<details>
<summary>Rationale</summary>
<p>

**Rationale:** Question-answer style uses sequential software-controlled flow (ATMs, wizards). Object-oriented allows user-controlled manipulation, form-based presents all fields simultaneously, and menu-driven offers hierarchical choices without strict sequencing.

</p>
</details>

## Question 4

What is the primary characteristic of a "Form-based" interaction style?

- [ ] Users manipulate virtual objects directly on the screen with immediate feedback.
- [ ] The system asks a series of questions to guide the user through steps.
- [x] It resembles a printed form where users fill out fields with validation.
- [ ] Navigation is primarily through a hierarchical menu tree with many options.

<details>
<summary>Rationale</summary>
<p>

**Rationale:** Form-based interfaces resemble printed forms with field completion and validation feedback. Direct manipulation is object-oriented, sequential questions are question-answer style, and hierarchical navigation is menu-driven.

</p>
</details>

## Question 5

Which interaction style is best suited for kiosks and involves navigating through a tree-like structure where users pick alternatives from offered options?

- [ ] Object-oriented with direct manipulation
- [ ] Question-answer with sequential flow
- [ ] Form-based with field validation
- [x] Menus and Windows (Menu-driven)

<details>
<summary>Rationale</summary>
<p>

**Rationale:** Menu-driven interfaces use tree navigation with offered alternatives, ideal for kiosks. Object-oriented allows free manipulation, question-answer enforces sequences, and form-based presents simultaneous fields—none match tree-based discovery.

</p>
</details>

## Question 6

What is the primary characteristic of a "Command Language" interaction style?

- [ ] Users interact with graphical elements and visual controls on screen.
- [x] Users type commands into a command line, requiring syntax knowledge.
- [ ] Users fill out forms with predefined fields and validation rules.
- [ ] Users answer a series of questions in a guided sequential flow.

<details>
<summary>Rationale</summary>
<p>

</p>
</details>

## Question 7

What is the primary characteristic of a "Natural Language" interaction style?

- [ ] Users interact with graphical elements and visual controls directly.
- [x] Users communicate using human language, which is difficult to interpret.
- [ ] Users fill out forms with predefined fields and validation feedback.
- [ ] Users answer a series of questions in a guided sequential order.

<details>
<summary>Rationale</summary>
<p>

**Rationale:** Natural language uses human language with inherent ambiguity challenges. Graphical elements, forms, and sequential questions all use structured interaction that eliminates ambiguity—opposite of natural language's challenge.

</p>
</details>

## Question 8

What is the primary characteristic of a "Direct Manipulation" interaction style?

- [ ] Users type commands into a command line with specific syntax.
- [x] Users directly manipulate graphical objects on screen with feedback.
- [ ] Users fill out forms with predefined fields and validation rules.
- [ ] Users answer a series of questions in a guided sequential flow.

<details>
<summary>Rationale</summary>
<p>

**Rationale:** Direct manipulation involves immediate visual feedback from graphical object manipulation. Command typing, form completion, and sequential questions all lack the direct spatial manipulation and immediate feedback characteristic of direct manipulation.

</p>
</details>

## Question 9

What is the primary characteristic of a "Fill-in-the-Blanks" interaction style?

- [ ] Users type commands into a command line with specific syntax.
- [ ] Users directly manipulate graphical objects on the screen visually.
- [x] Users fill in predefined fields, often with validation and feedback.
- [ ] Users answer a series of questions in a guided sequential order.

<details>
<summary>Rationale</summary>
<p>

**Rationale:** Fill-in-the-blanks (form-based) involves completing predefined fields with validation. Command typing requires syntax knowledge, direct manipulation uses spatial interaction, and sequential questions enforce order—forms present all fields simultaneously.

</p>
</details>
